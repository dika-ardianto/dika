📋 Panduan Setup Google Apps Script

1. Buka script.google.com dan buat proyek baru.

2. Copy paste kode dari file Code.gs ke editor.

3. Klik Deploy → New deployment → Web app

4. Set "Execute as" = Me, "Who has access" = Anyone

5. Klik Deploy, copy URL yang muncul.

6. Jalankan fungsi initSheets() sekali untuk membuat sheet otomatis.

7. Ganti nilai APPS_SCRIPT_URL di HTML ini dengan URL tersebut.
